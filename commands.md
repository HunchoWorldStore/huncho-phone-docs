# Commands

| Command | Who | What it does |
| --- | --- | --- |
| `F1` | Everyone | Open the phone, press again to put it away (rebindable) |
| Hold `Left Alt` | Everyone | Look around with the phone open, aim the camera |
| `/phoneprop [model]` | Admins | Set where a phone sits in the hand (E: open / closed) |
| `/phoneprop export` | Admins | Save every position to `prop_defaults_export.json` |
| `/phone_removepost <id>` | Admins | Remove a social post |
| `/phone_ban <app> <username> <hours> [reason]` | Staff, console | Ban an account from posting (0 hours = for good) |
| `/phone_unban <app> <username>` | Staff, console | Lift the ban |
