# Huncho Phone

A complete FiveM smartphone: ten phone models with real foldables and working keys, FaceLink video calls, social apps, Mail, music and more. It runs on **Qbox, QBCore and ESX** and detects your other scripts by itself.

`Qbox` · `QBCore` · `ESX Legacy` · `ox_lib + oxmysql` · `5 languages`

## Two editions

| Edition | Phones | Everything else |
| --- | --- | --- |
| Huncho Phone | All 10 models: Island, Edge, Flip, Fold, Duo, Tri, Bold, Spin, Snap, Snap Max | The same apps, integrations, languages, staff tools and developer API |
| Standard edition | 5 models: Island, Edge, Flip, Fold, Duo | The same apps, integrations, languages, staff tools and developer API |

Both are one resource called `hw_phone`. The 3D phone models are inside it, so there is nothing else to install.

Start with [Installation](installation.md).
