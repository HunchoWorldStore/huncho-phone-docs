# Huncho World Game Pack

Eight table games in one resource. Players sit at real tables in synced seated animations, see the real pieces move, and play for free or for cash. Bots fill empty seats.

{% hint style="success" %}
**Get it:** [Huncho World Store](https://hunchoworldstore.github.io/)\
**Support & updates:** [Huncho World Discord](https://discord.gg/hP8VTtwgs5)
{% endhint %}

| Game | What's in it |
| --- | --- |
| [**Beer Pong**](games/beer-pong.md) | Real ball physics, your character throws and drinks, 1v1 or 2v2, bots, betting and side bets, spectator cameras |
| [**Card Hub**](games/card-hub.md) | Crazy 8s, Last Card, Spades, Tonk and Go Fish, with the cards on the table in front of each player |
| [**Cee-lo Street Dice**](games/cee-lo.md) | Cee-lo Bank, Head-Up, Pot Run, Street Craps, Over/Under 7 and Pig, with every bet held in escrow |
| [**Dominoes**](games/dominoes.md) | 8 modes, a streamed domino table, case and tiles, the dealer washes the tiles by hand |
| [**Oh Bih Please**](games/oh-bih-please.md) | The party card game: truth, dare, shots and wild cards, Clean or Spicy |
| [**Oh Bih Roulette**](games/oh-bih-roulette.md) | A game-show wheel on the table: truth, dare, hot seat, jackpot, and Dare or Pay with play money |
| [**Slumlords**](games/slumlords.md) | A 2-6 player property trading board game with a live board, 3D dice, pins, houses and hotels |
| [**Tumbling Towers**](games/tumbling-towers.md) | Pull a block, don't drop the tower. Whoever knocks it over takes a whiskey shot |

## Every game includes

* Auto-detection of **Qbox, QBCore, ESX** or standalone, your inventory and your target resource
* **ox\_target, qb-target**, or walk up and press **E**
* Start a table with **the item, the command, or both**, set per game
* **Bots** for empty seats
* **Free or cash games**, with stakes and payouts handled on the server
* **5 languages:** English, Spanish, Portuguese (Brazil), French and German
* One [admin panel](admin-panel.md) for the whole pack: live tables, on/off per game, stake limits, permanent tables
* Open configs, locales and bridges (they stay readable after escrow)
* Item files and images for every supported inventory
