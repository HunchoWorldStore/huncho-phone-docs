# Supported scripts

Everything is detected when the phone starts. Force a choice in `Config.Integrations`.

| Type | Supported |
| --- | --- |
| Framework | Qbox (qbx\_core), QBCore, ESX Legacy, standalone |
| Inventory | ox\_inventory, qb-inventory, ps-inventory, lj-inventory, qs-inventory, wasabi\_inventory, ak47\_inventory, tgiann-inventory, core\_inventory |
| Banking | fd\_banking, Renewed-Banking, okokBanking, qs-banking, qb-banking, esx\_banking, omes\_banking, tgiann-bank, wasabi\_banking, or any banking script that uses the framework's bank money |
| Garages | jg-advancedgarages, qs-advancedgarages, cd\_garage, okokGarage, tgiann-garage, qbx\_garages, qb-garages, esx\_garage, or any `player_vehicles` / `owned_vehicles` setup |
| Housing | bcs\_housing (locks, doors, keys), ps-housing, qs-housing, qb-houses, nolag\_properties, qbx\_properties, tgiann-house |
| Voice | pma-voice (calls, mute, speaker), mumble-voip, saltychat |
| Vehicle keys | qbx\_vehiclekeys, qb-vehiclekeys, qs-vehiclekeys, wasabi\_carlock, MrNewbVehicleKeys, Renewed-Vehiclekeys, cd\_garage, t1ger\_keys |
| Fuel | ox\_fuel, LegacyFuel, cdn-fuel, ps-fuel, lj-fuel, lc\_fuel, Renewed-Fuel |
| Weather | cd\_easytime (forecast), any other weather script (live conditions) |
