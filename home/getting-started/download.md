# Download your purchase

Every Huncho World script is delivered through **Cfx.re Keymaster**, to the Cfx.re account you signed in with at checkout.

1. Go to [keymaster.fivem.net](https://keymaster.fivem.net) and sign in with **the same Cfx.re account** you used at checkout.
2. Open **Granted Assets** and download the script.
3. Unzip it and put the resource folder in your server's `resources` folder. **Don't rename the resource folder.**
4. Follow the script's **Installation** page to add the items and the `ensure` line.

| Script | Installation guide |
| --- | --- |
| Huncho Designer Bookbags | [Installation](https://huncho-world-store.gitbook.io/huncho-world-store-docs/huncho-designer-bookbags/getting-started/installation) |
| Huncho Job Center | [Installation](https://huncho-world-store.gitbook.io/huncho-world-store-docs/huncho-job-center/getting-started/installation) |
| Huncho NPC Police | [Installation](https://huncho-world-store.gitbook.io/huncho-world-store-docs/huncho-npc-police/getting-started/installation) |
| Huncho Phone | [Installation](https://huncho-world-store.gitbook.io/huncho-world-store-docs/huncho-phone/installation) |
| Huncho World Game Pack | [Installation](https://huncho-world-store.gitbook.io/huncho-world-store-docs/huncho-world-game-pack/getting-started/installation) |

{% hint style="info" %}
**Don't see it in Granted Assets?** Check you're signed in to the account you bought with. If it's still missing, open a ticket in the [Huncho World Discord](https://discord.gg/hP8VTtwgs5) with your Tebex transaction ID (it starts with `tbx-`).
{% endhint %}

## Updates

New versions show up in the same place. Download the new version and follow the script's **Updating** page so you keep your config.
