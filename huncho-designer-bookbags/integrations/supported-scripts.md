# Supported scripts

Detected automatically when `Config.Framework` and `Config.Inventory` are `'auto'`.

**Frameworks:** Qbox, QBCore, ESX

| Inventory | Wear and open | Police searches | Blocks bags in bags |
| --- | --- | --- | --- |
| ox\_inventory | Yes | Yes | Yes |
| qb-inventory 2.0+ | Yes | Yes | Moves them back |
| qb-inventory before 2.0 | Yes | No | No |
| ps-inventory, lj-inventory | Yes | No | No |
| qs-inventory | Yes | Yes | Moves them back |
| wasabi\_inventory | Yes | Yes | Yes |
| tgiann-inventory | Yes | Yes | Yes |
| ak47\_inventory | Yes | Yes | Moves them back |

Anything else works through the [custom bridge](../integrations/custom-scripts.md).

**Targets:** ox\_target or qb-target for shop clerks, or press **E** without either.
